## 🌟 Devenir Contributeur

### Première Contribution ?

Nous adorons accueillir de nouveaux contributeurs !

**Par où commencer** :
1. 📖 Lire [CONTRIBUTING.md](./docs/CONTRIBUTING.md)
2. 🔍 Trouver une issue `good first issue`
3. 💬 Commenter l'issue pour indiquer votre intérêt
4. 🔨 Créer votre fork et commencer
5. 📤 Soumettre une pull request

### Reconnaissance

**Chaque contribution compte !** Peu importe sa taille :

- ✅ Correction de typo dans la documentation
- ✅ Rapport de bug détaillé
- ✅ Suggestion d'amélioration
- ✅ Review de code
- ✅ Réponse dans les discussions

**Tous les contributeurs seront** :
- 📝 Listés dans ce fichier
- 🏆 Mentionnés dans les release notes
- 💬 Crédités sur les réseaux sociaux
- 🎖️ Remerciés publiquement
